# Material (Originale)

Hier liegen die gelieferten Originaldateien. Sie werden nicht verändert.

- `logo/` – Logo (PNG/WebP, transparent, 1239 × 658)
- `kraehe/` – Krähe (krähe_fleck2.jpg)
- `schriften/` – Schriften-ZIP (Cantarell, Noto Sans, Indie Flower)

Aus den Schriften werden lateinisch reduzierte WOFF2-Dateien nach `app/fonts/` erzeugt
(siehe README.md im Projektwurzelverzeichnis). Nur diese und die OFL-Lizenztexte werden ausgeliefert.
